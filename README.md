# pw_teaser for TYPO3 CMS – Community Fork (TYPO3 13.4 compatible)

This repository is a community-maintained fork of the original
[pw_teaser](https://github.com/a-r-m-i-n/pw_teaser) extension by Armin Vieweg.

The original project is no longer actively maintained.  
To keep this great extension usable in current TYPO3 installations, we updated
and adapted it for **TYPO3 13.4** and replaced deprecated or removed APIs as required.

All credits for the original concept and implementation go to  
**Armin Vieweg and all contributors**.

## What is pw_teaser?

Create powerful page teasers in TYPO3 CMS with data from page properties and
its content elements. Built with Extbase and the Fluid template engine.

## Features

- Show lists of pages (similar to TYPO3’s `menu_pages` / `menu_subpages`)
- Extensive filtering options for pages
- Nested or flat teaser list rendering
- Fully customizable Fluid templates
- Template presets
- Pagination support
- Extendable using EventListeners
